## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing(组件内紧凑间距) |
| md | 16px | Default element spacing(默认:卡片内边距、网格 gap、layout 水平 padding) |
| lg | 24px | Section padding(区块内边距) |
| xl | 32px | Layout gaps(区块间距) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing(首页 py-10 及以上大留白) |

与现状对齐:`home.layout` / `tool.layout` 的 `px-4`(16px)容器水平内边距、home.vue `py-10`(40px)主区上边距沿用 — 40px 是 4 的倍数,归入 xl~2xl 之间的合规使用。

Exceptions:
- **44px 触控目标**(D-21):Button / ThemeToggle 等交互组件 min-width/min-height ≥ 44px — 非间距 token,是组件尺寸规则,8-point 尺度的显式例外。
- **存量 12px(`py-3`)**:双 layout header 与「返回首页」按钮现用 `py-3`/`py-1.5`,属 D-15 全量迁移面;迁移时归一到 8px 或 16px 核心档,不新增 12px 用法。
- Tailwind 4 默认 0.25rem(4px)步进仍可用,但新代码优先上表核心档。

|------|------|--------|-------------|
| Body | 16px | 400 | 1.6(`base.css` 现状延续;输入类控件亦为 16px,满足 D-21) |

**硬规则(迁移即断言,D-21):** input / textarea / select 最终渲染字号 ≥ 16px — 六件套默认 16px + `base.css` 对原生标签的 16px 兜底规则(防绕过组件直写);mono 字体(`--font-mono`)用于品牌、NEW 徽标、代码与工具输出,字号沿上表四档。

## Color

60/30/10 结构(以默认暗色主题为基准;亮色为 D-07 策略下的起点值,最终由 D-20 对比度单测裁决 — 改色即红):

| Role | 暗色(默认;值锁定,D-12) | 亮色(D-07 起点值) | Usage |
|------|--------------------------|--------------------|-------|
| Dominant (60%) | `--color-bg: oklch(0.16 0.02 260)` | `oklch(0.97 0.008 260)`(浅冷灰底,保持 260 色相、偏离纯白) | 页面背景 |
| Secondary (30%) | `--color-surface: oklch(0.2 0.025 260)` / `--color-surface-raised: oklch(0.24 0.03 260)` | surface `oklch(0.99 0.004 260)` / raised `oklch(0.94 0.01 260)` | 卡片、header/footer、输入框底 |
| Accent (10%) | 霓虹三色(锁定):cyan `oklch(0.85 0.16 195)`、magenta `oklch(0.72 0.24 330)`、yellow `oklch(0.92 0.19 105)` | 深霓虹体系:深青蓝 `oklch(0.42 0.10 230)`、深紫红 `oklch(0.40 0.16 330)`、琥珀/金褐 `oklch(0.40 0.10 70)` | 见下方保留清单 |
| Text | `--color-text-primary: oklch(0.93 0.01 260)` / `--color-text-muted: oklch(0.65 0.02 260)`(锁定) | text-primary `oklch(0.24 0.02 260)` / text-muted `oklch(0.46 0.02 260)` | 正文永远用中性 text 色,霓虹不用于正文小字(PITFALLS 5) |
| Destructive | `--color-danger`(语义层新增,D-10):暗色起点 `oklch(0.65 0.19 25)` + 背景/边框变体 | 亮色起点 `oklch(0.50 0.19 25)` | 仅错误态与破坏性指示(Input 错误边框/文案、校验失败) |
| 功能色 | `--color-success`(起点 `oklch(0.75 0.15 150)`)、`--color-warning`(起点 `oklch(0.80 0.15 85)`)+ 各自背景/边框变体(D-10) | 对应亮色变体(单测裁决) | 状态反馈;warning 与霓虹黄原语同族但经语义层消费,禁止页面直连原语 |

**Accent reserved for(10% — 暗/亮同规则,逐项列举):**
- 品牌标识:logo「little-utils」(cyan + glow-cyan 阴影)、footer 品牌字
- `focus-visible` 焦点环:全站统一霓虹青(D-19)
- 工具卡 hover 边框、链接 hover 态(cyan,现 ToolCard 行为入 Card 组件)
- Tabs 活动态指示(文字/下划线,cyan)
- NEW 徽标(magenta,现 ToolCard 行为)
- ThemeToggle 当前态点缀(magenta)
- 电光黄:仅点缀性数值/单字符强调(如时间戳结果值),不用于正文、不大面积铺色

**发光(glow)规则(D-08):** 暗色保留现有 `--shadow-glow-*` 强度(值锁定);亮色下 glow 阴影透明度降至约一半、颜色换深霓虹血统;glow 仅限装饰/品牌层,工具操作区禁用(ARCHITECTURE/PITFALLS:风格化隔离)。大范围装饰滥用留给 Phase 6 装饰层。

**对比度红线(D-20):** 所有「文字用途」色对(text/bg、霓虹文字用途、功能色及其背景变体)双主题全部 ≥ 4.5:1;色值单点维护进 TS 常量模块,vitest 断言 WCAG 对比度,跑进现有 `test:unit` 命令。本表 oklch 数值为 executor 起点值,若单测不达标,以保持 D-07 策略(亮色加深降饱和、暗色不动)为前提调整数值直至达标。
